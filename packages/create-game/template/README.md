# __NAME__

Generated by `kits/new-game.mjs` from the 0801564.xyz kits. This is a complete, working party game (Lucky Draw) to be
rewritten into your own. Everything in `kit/` is copied verbatim from the kits and is not edited here.

```
npm install
npm test                 # engine rules, room integration, screens
npm run typecheck
npm run dev:server       # builds the web app, then Worker + Durable Objects on http://localhost:8787
npm run dev:web          # (second terminal) Vite with hot reload on :5173, proxied to the Worker
```

## Where things live
| path | what it is | you edit it? |
|---|---|---|
| `packages/engine/src/lucky.ts` | **the rules**: pure functions, JSON state, seeded, per-viewer views | yes: this is the game |
| `packages/engine/src/roster.ts` | room-code letters (dev placeholder, see the note in the file) | before deploy |
| `packages/server/src/logic.ts` | wires the rules into the room contract | when the engine's exports change |
| `packages/server/src/room.ts` | the Durable Object: site id, plugins | rarely |
| `packages/server/wrangler.jsonc` | Worker config: bindings, vars, routes | before deploy |
| `packages/web/src/screens/*` | Home (entry), Online (lobby/game/TV/results), Local (pass the phone) | yes |
| `packages/web/src/styles.css` | game styles, token colours only | yes |
| `kit/*` | the shared kits | **no**: change the kit, copy it again |

## Turning Lucky Draw into your game
1. `packages/engine/src/lucky.ts`: replace the state, `act`, `tick`, `view`. Keep the rules of the file: pure, JSON-only, never put another player's secret in `view()`.
2. Update `packages/engine/src/lucky.test.ts` (determinism, JSON-safe and no-leak helpers are there to reuse).
3. `packages/server/src/logic.ts`: point it at your functions; set `minPlayers`, `maxPlayers`.
4. Screens: replace `Hand`, `Table`, `RevealPanel`; keep the lobby/results/display/pass-the-phone wiring.
5. Work through `docs/NEW_GAME_CHECKLIST.md` (landing, play, cast registration; secrets; icons).

Dev-only notes: `.dev.vars` (copy `.dev.vars.example`), the local `STATS_URL` in `wrangler.jsonc` should stay unset while developing.
